# PowerBI_Relatorio_Satisfacao
📊 Relatório de Pesquisa de Satisfação dos Colaboradores

Este projeto apresenta um painel interativo desenvolvido para analisar os resultados de uma Pesquisa de Satisfação aplicada aos colaboradores de uma organização. O painel tem como objetivo fornecer uma visão clara e dinâmica sobre os níveis de satisfação dos funcionários, bem como informações demográficas e operacionais relevantes.
Link para acesso ao relatorio: https://app.powerbi.com/view?r=eyJrIjoiMjgxMmNlY2ItMjEzZC00OTlhLTliNmItMDE2MzA5MDdhYmIzIiwidCI6Ijg1ZGU1OTA5LTZlOGItNGEwYy1iYTIzLWYwMzYyYzcyZDc3NiJ9

🧩 Funcionalidades

    Total de perguntas respondidas

    Quantidade de cargos e total de funcionários

    Distribuição de idade dos colaboradores

    Principais fontes de recrutamento

    Evolução da quantidade de funcionários por ano

    Comparativo de satisfação entre duas entrevistas (Entrevista 1 e Entrevista 2)

    Análise de satisfação por temas: Saúde, Carga Horária e Salário

    Filtro por regiões (Alpha, Beta, Gama, Sul)

📌 Insights Possíveis

    Identificar aumento ou queda na satisfação dos colaboradores ao longo do tempo

    Comparar percepções sobre salário, carga horária e saúde entre diferentes momentos

    Verificar canais mais eficazes de recrutamento

    Analisar perfis etários predominantes

    Acompanhar o crescimento do quadro de funcionários ao longo dos anos

🛠️ Tecnologias Utilizadas

    Power BI: Desenvolvimento do dashboard e criação de visualizações interativas.

    Excel (bd_integrantes.csv e BD-RH.xlsx): Fonte de dados para a análise de vendas.

    DAX (Data Analysis Expressions): Criado para cálculos e métricas personalizadas.
